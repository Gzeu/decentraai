# WP-001.4 Workspace Integration

## Objective

Integrate `crates/inference-adapter` into the repository's existing Cargo workspace without deleting or rewriting existing members and dependencies.

## Why this is a separate milestone

A crate directory can compile independently while still being absent from the root workspace. Full integration requires the crate to participate in the shared workspace dependency resolution, lockfile and workspace checks.

## Safe procedure

From the repository root:

```bash
cargo metadata --no-deps
```

Inspect the root `Cargo.toml` and preserve every existing workspace member. Add only:

```toml
"crates/inference-adapter"
```

Then run:

```bash
cargo update --workspace
cargo fmt --all -- --check
cargo check --workspace
cargo test --workspace
cargo clippy --workspace --all-targets --all-features -- -D warnings
```

## Acceptance criteria

- `cargo metadata --no-deps` lists `decentraai-inference-adapter`.
- Root `Cargo.lock` contains the adapter dependencies.
- Existing workspace members remain unchanged.
- Adapter unit and HTTP contract tests pass through the workspace.
- Existing workspace tests still pass.
- Clippy has no new warnings.
- The CI workflow validates the adapter as part of the full workspace.
- The tracker records the commit, commands and results.
